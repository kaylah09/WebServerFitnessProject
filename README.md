WebServerFitnessProject

Project Description

WebServerFitnessProject is an ASP.NET Core MVC web application designed to help users explore fitness exercises, view workout routines, and organize their workout schedules.

This application is being developed as a group project for our Web Server Development course.

Purpose

The purpose of this project is to create a user-friendly fitness website that allows users to browse exercises, discover workout routines, and plan their fitness activities in one place.

Planned Features

Home Page: Introduction to the fitness website.

Exercise Library: Browse exercises organized by muscle group.

Workout Routines: Explore different workout routines.

Workout Calendar: Schedule and organize workouts.

To-Do List: Keep track of planned workout activities.

About Page: Information about the project and team members.
